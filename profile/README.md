# Bite Map

An Android app that my husband and I use to log our toddler's meals, so that we can see what we've been serving him and avoid falling into a rut.

We want to raise an adventurous eater, not what we jokingly call a "dino chicken nugget kid." As two working parents, we kept cooking the same meals because we couldn't keep track of what we'd made recently. Bite Map is a shared log we use to record each meal, how much was eaten, and some simple descriptors (cuisine type and food groups) to help us categorize each meal. It syncs between our two phones and works offline, making it easy to spot when we're falling into a rut.

I wrote the requirements, made the product trade-off calls, and tested every feature on my phone. I used Claude Code for implementation and Google Stitch for design, working from a written constitution, spec and decision log.
